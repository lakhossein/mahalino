# محلینو+ — نسخهٔ ۰.۳۳

نسخهٔ مستقل مبتنی بر نسخهٔ ۰.۳۲ از کامیت `1c78eda65e0efb0d6c64156041afcb84bfec921e`، با حفظ قراردادهای سازگاری و امکانات موجود.

## ساخت

```sh
node V0.33/build_v033.js
node V0.33/build_v033.js --check
```

خروجی: `Mahalino+V0.33.html`. پوشهٔ ۰.۳۳ مستقل است و برای ساخت به فایل‌های نسخه‌های قبلی نیاز ندارد.

- `templates/app.html`: ساختار صفحه، بدون کدهای حجیم درون‌خطی.
- `src/legacy/`: ۳۲ بخش موضوعی استخراج‌شده از اجرای تثبیت‌شدهٔ قبلی؛ ترتیب و دامنهٔ اجرای آن‌ها در خروجی عوض نشده است.
- `src/v32-payment.js`: ماژول مستقل پرداخت؛ save نتیجهٔ موفق/ناموفق دارد و callback پس از ثبت debit اجرا می‌شود.
- `src/v32-*.js` و CSSها: ماژول‌های کشف نیاز، راهنمای قطعی، جریان‌ها، پرداخت و رابط.
- `build-manifest.json`: نگاشت صریح تمام بخش‌ها.
- `build/assemble.cjs`: مونتاژ قابل آزمون، بدون جایگزینی‌های متنی روی HTML نسخهٔ ۰.۲۹.

کلید ذخیره‌سازی `mahalino_v33` است؛ در صورت نبود دادهٔ این نسخه، دادهٔ ۰.۳۲ و سپس نسخه‌های قدیمی‌تر خوانده می‌شوند. دادهٔ ۰.۳۲ بازنویسی نمی‌شود. بازنشانی فقط state، snapshot بازیابی و کلیدهای نشست اختصاصی ۰.۳۳ را پاک می‌کند و یک state خالی صریح نگه می‌دارد تا مهاجرت خودکار دوباره انجام نشود. تنظیمات و پایگاه‌های مشترکِ بدون نسخه حذف نمی‌شوند. نام‌های داخلی سازگار مانند `E30` و `e31Prefill` حفظ شده‌اند.

## آزمون

```sh
npm ci --prefix V0.33/qa
V0.33/qa/node_modules/.bin/playwright install --with-deps chromium
bash V0.33/qa/run-quality-gate.sh
```

دروازهٔ کیفیت شامل تمام مجموعه‌های مرورگری قبلی روی خروجی ۰.۳۳، کنترل پوشش قبلی، ساخت مستقل، بررسی منابع، مهاجرت بدون تغییر دادهٔ نسخه‌های پیشین و تست‌های خطای سازنده است. قرارداد تطابق تاریخی ۰.۳۱ و ۰.۳۲ با fixtureهای ثابت و کنترل hash بر روی خود نسخه‌های بایگانی‌شده اجرا می‌شود؛ ساخت مستقل ۰.۳۳ چنین وابستگی‌ای ندارد.

## حدود ری‌فکتور

این تغییر بدهیِ سازندهٔ مبتنی بر وصله‌های تاریخی، کدهای حجیم درون HTML و تبدیل سراسری متن در زمان ساخت را برطرف می‌کند. الگوی سراسری و زنجیرهٔ wrapperهای قدیمی، برای حفظ رفتار، همچنان باقی است؛ این تغییر ادعای حذف همهٔ بدهی‌های معماری یا افزایش سرعت اجرای مرورگر ندارد.

سامانه همان نمونهٔ نمایشی و هدایت مبتنی بر قواعد قبلی است؛ سرویس یا قابلیت جدیدی اضافه نشده است.

قراردادهای همزمانی، بسته‌بندی، snapshotهای تاریخی و محدودیت‌های باقی‌مانده در [قراردادهای اجرا](../docs/Mahalino_Runtime_Contracts_FA.md) مستند شده‌اند.
