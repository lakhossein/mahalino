# UI-IMPROVEMENTS — Mahalino+ V0.28

## کارت محله (`.hcard`)
- تمام‌عرض (max 600px) در گرید `.chcards`؛ سربرگ: تصویر ۸۸×۶۰ + نام + زیرنویس + نشان نمرهٔ تطبیق.
- شبکهٔ پاسخ‌گوی `auto-fit minmax(150px,1fr)` از شش سلول داده (برچسب کوچک بالای مقدار پررنگ) — اجارهٔ نمونه، ودیعهٔ نمونه، هر متر آگهی، بازهٔ آگهی، تغییر یک‌ساله/ماهانه (سبز/سرخ معنایی).
- بلوک جدا «مکان‌های مهم» (یا «ثبت نشده»)؛ ردیف اکشن‌ها با حاشیهٔ جدا.
- توکن‌ها و شعاع‌ها از Design System (var(--card/--line/--bg)، radius 16/11).

## کامپوزر (`.ch-main .cwr`)
- کادر گرد ۲۲px با border و سایهٔ لطیف؛ textarea بدون border داخلی، padding ۱۱/۱۰، font 14px/1.8.
- رشد خودکار: `height:auto → min(scrollHeight,200px)`؛ اسکرول داخلی پس از سقف.
- دکمهٔ پیوست و ارسال ۴۰×۴۰ (ارسال با متن، وزن ۸۰۰)؛ چیدمان `align-items:flex-end`.
- موبایل: حاشیهٔ کمتر و شعاع ۱۸px. Enter=ارسال (با گارد IME)، Shift+Enter=خط جدید.

## اکشن‌های پیام (`.macts`)
- شناور بالای هر حباب، نمایش با هاور/فوکوس (در لمس همیشه نیمه‌نمایان)؛ دکمه‌های ۲۶px آیکونی با `title` + `aria-label`.
- کاربر: ویرایش (بازگرداندن متن به کامپوزر و حذف پیام) → کپی → حذف؛ دستیار: کپی.
- کپی با `navigator.clipboard` و fallback textarea.

## پیشنهادهای زمینه‌ای
- حذف ردیف ثابت (نقشه/درخواست‌ها/راهنما)؛ ردیف وقتی خالی است مخفی (`[hidden]{display:none}`).
- خوش‌آمد: پیام gate با چیپ‌های کشفِ چهار گروه (معامله/بازار/قرارداد/حساب) — ۱۲ ورودی، همگی واقعاً اجرا می‌شوند.
- در جریان فلو: ردیف خالی — چیپ‌های خود گام نقش پیشنهاد را دارند.

## حالت تاریک
- توکن‌ها: `--hov/--hov2/--sel` (روشن: مشکی شفاف؛ تاریک: خاکستری روشن شفاف) — hover همیشه متمایز، selected جدا از hover، متن/آیکون با کنتراست حفظ‌شده؛ hover قهوه‌ای/نامرئی قبلی حذف شد.

## آیکون‌ها (Tabler)
- ۵۲ آیکون outline رسمی، شبکهٔ ۲۴×۲۴، stroke 2، درون‌ریزی build-time از `assets/icons/` (بدون CDN) + فایل LICENSE.
- نگاشت‌ها: `ICONS` (فلوها/ابزارها)، `E27_IC` (سایدبار: plus/search/message-circle/panel-right-collapse-expand/wallet/user/settings/trash/pencil/pin/pin-off)، `E22.ICO` (sun/moon/message-circle).
- جایگزینی ایموجی‌ها (📌/📍) با pin/pin-off؛ `ico()` حالا stroke-width 2 برای یکدستی.
