## ساخت

```sh
node V0.32/build_v032.js
node V0.32/build_v032.js --check
```

خروجی: `Mahalino+V0.32.html`. پوشهٔ ۰.۳۲ مستقل است و برای ساخت به فایل‌های نسخه‌های قبلی نیاز ندارد.

- `templates/app.html`: ساختار صفحه، بدون کدهای حجیم درون‌خطی.
- `src/legacy/`: ۳۲ بخش موضوعی استخراج‌شده از اجرای تثبیت‌شدهٔ قبلی؛ ترتیب و دامنهٔ اجرای آن‌ها در خروجی عوض نشده است.
- `src/v32-*.js` و CSSها: ماژول‌های کشف نیاز، راهنمای قطعی، جریان‌ها، پرداخت و رابط.
- `build-manifest.json`: نگاشت صریح تمام بخش‌ها.
- `build/assemble.cjs`: مونتاژ قابل آزمون، بدون جایگزینی‌های متنی روی HTML نسخهٔ ۰.۲۹.

تغییرات نمایشی فقط شناسهٔ نسخه هستند. کلید ذخیره‌سازی `mahalino_v32` است؛ در صورت نبود دادهٔ این نسخه، دادهٔ ۰.۳۱ و سپس نسخه‌های قدیمی‌تر خوانده می‌شوند. دادهٔ ۰.۳۱ بازنویسی نمی‌شود. بازنشانی فقط state، snapshot بازیابی و کلیدهای نشست اختصاصی ۰.۳۲ را پاک می‌کند و یک state خالی صریح نگه می‌دارد تا مهاجرت خودکار دوباره انجام نشود. تنظیمات و پایگاه‌های مشترکِ بدون نسخه حذف نمی‌شوند. نام‌های داخلی سازگار مانند `E30` و `e31Prefill` حفظ شده‌اند.

## حدود ری‌فکتور
