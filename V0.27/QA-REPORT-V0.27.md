## End-to-End (موفق/خطا/بازگشت) برای سناریوهای اصلی
- **اجاره:** موفق (ودیعه→بدون سقف→بازار→کارت→انتخاب)؛ خطا (مبلغ نامفهوم)؛ بازگشت (`↩ بازگشت`) ✅
- **خرید:** موفق (بودجه→…→esc1→escC→آزادسازی)؛ خطا (درصد نامعتبر/بودجهٔ نامفهوم)؛ بازگشت (esc1→escA) ✅
- **کیف پول:** موفق؛ خطا (مبلغ نامعتبر، پرداخت ناموفق، ثبت تکراری)؛ بازگشت (انصراف/تلاش مجدد) ✅
- **بازنشانی:** موفق + ماندگاری پس از reload ✅

## باقی‌مانده (صادقانه)
1. تست آپلود واقعی فایل (E21 tray) اجرا نشد — کد لمس نشده، ریسک پایین.
2. تست ویژوال ۱۴۴۰px/تبلت و keyboard-only جامع اجرا نشد (محدودیت ابزار). ساختار CSS پاسخ‌گو بازبینی شد.
3. تصاویر دموی تخلیه، شبیه‌سازی‌شده‌اند و این موضوع در UI برچسب خورده است.
