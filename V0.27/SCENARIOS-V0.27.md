# SCENARIOS — Mahalino+ V0.27

همهٔ سناریوها بدون AI واقعی، با موتور قاعده‌محور (SCRIPTS + RINT + E21/E23/E25 + E27) اجرا می‌شوند. برای هر سناریو: مسیر موفق، مسیر خطا، و مسیر اصلاح/بازگشت تست شده است (QA-REPORT).

## ۰) منوی گفت‌وگویی (gate)
گام‌ها: سلام → ثبت محل کار/مدرسه (قابل رد) → منوی مسیرها (اجاره/خرید/اجاره تضمینی/درآمد اجاره/پروژه‌ها/ساخت/اقامتگاه/خدمات).
خطا: ورود نامعتبر → پیام و درخواست مجدد. بازگشت: چیپ‌های منو / `↩ بازگشت`.

## ۱) اجاره (rent) — ۱۷ گام
ودیعه (آزاد/«بدون سقف») → سقف اجاره (آزاد/«بدون سقف») → اهمیت‌ها (۱–۵) → خواب → موقعیت → سن بنا → متراژ → طبقه → آسانسور/پارکینگ → اولویت آزاد (تا «تمام») → محله‌ها (کارت/مقایسه) → **بازار (کامپوننت تصویری)** → آگهی‌ها (**کارت عمودی**) → روز/ساعت بازدید → ثبت بازدید (۲۰ توکن) → فرم بازدید → قرارداد → فسخ/تخلیه.
خطا: مبلغ نامفهوم، محلهٔ ناشناخته، متن خالی — همگی پیام راهنما دارند (بدون بن‌بست).
بازگشت: `↩ بازگشت` (ceBack) و چیپ‌های «تغییر اولویت‌ها/محلهٔ دیگر».

## ۱.الف) فسخ و تخلیهٔ هوشمند (زیرسناریو)
termq → دلیل → زمان → صورت‌جلسه (قالب) → تأیید موجر → **tai: گام ۱ روز ورود (لغزنده + زوم + عکس خودم) → گام ۲ روز تخلیه → گام ۳ تحلیل (نمایشی) یا رد کردن** → تسویهٔ ودیعه.
هر گام Stepper و امکان بازگشت («بازگشت به گام ۱») دارد.

## ۲) خرید (buy) — ۲۰ گام
بودجه (دقیق/«X به بالا»/«X حداکثر»/«بدون بودجهٔ مشخص»/اعداد بدون سقف) → اهمیت‌ها → بازه‌های سن/متراژ/قیمت‌متر/طبقه → خواب → ویژگی الزامی → محله‌ها → **بازار تصویری (با KPI بودجه)** → تأمین بودجه (اختیاری) → آگهی‌ها (**کارت عمودی**) → وضعیت سند → گزارش حقوقی (۱۰۰ توکن) → **توافق پرداخت**:
- مرحله‌ای: تعداد مراحل → درصدها (جمع ۱۰۰؛ «تقسیم مساوی») → `escC` آزادسازی مرحله‌ای.
- یکجا: **esc1 (خلاصهٔ توافق) → تأیید → escC (۱۰۰٪ هنگام سند)** — بن‌بست قبلی رفع شد.
خطا: درصد نامعتبر، بودجهٔ غیرقابل فهم → پیام راهنما. بازگشت: از هر دو مسیر به escA.

## ۳) سرمایه‌گذاری (invb/invr)، پروژه‌ها (mkt)، ساخت (build)، اقامتگاه (stay)
بدون تغییر منطقی؛ کارت‌های اقامتگاه عمودی شدند و کامپوزر یکتاست. مسیر خطا/بازگشت طبق چیپ‌های هر گام.

## ۴) بازار محله (RINT.scMarket) — آزاد
«بازار X» / «بازار اجارهٔ X» / «مقایسهٔ X و Y» / «امتیاز محله‌ها» → کامپوننت تصویری + اکشن‌ها. بدون محله → درخواست نام محله (بدون بن‌بست).

## ۵) کیف پول و توکن (E27)
منو (موجودی هر دو حساب) → شارژ: مبلغ (خطا: نامفهوم/صفر) → خلاصهٔ تراکنش → تأیید → درگاه نمایشی (موفق/ناموفق قابل انتخاب برای تست) → نتیجه + کد پیگیری. مسیرهای خطا: پرداخت ناموفق (بدون تغییر موجودی + تلاش مجدد/انصراف)، ثبت تکراری (گارد کد tx + toast)، انصراف. تاریخچهٔ تراکنش‌ها. خرید توکن از بسته‌ها (مودال پرداخت قبلی). استقلال کامل کیف/توکن.

## ۶) ابزارهای مستقل E23/E25
تبدیل ودیعه↔اجاره، راهنمای قرارداد، چک‌لیست بازدید، سنجش توان، دوئل محله‌ها، کمیسیون، دفتر یادآور (سقف ۵۰)، آموزش افزایش اجاره، بررسی سرمایه‌گذاری، خلاصهٔ مشاور — همگی داخل گفت‌وگو و بدون تغییر رفتار.

## ۷) درخواست‌ها و قراردادها
«درخواست‌ها» → مودال با فیلتر دسته/وضعیت، جزئیات، «ادامه در گفت‌وگو». قراردادها از تنظیمات حساب.

## ۸) حساب و بازنشانی
پروفایل (تب‌ها: خلاصه/کیف/توکن/قرارداد/تنظیمات)، تم روشن/تاریک، **بازنشانی واقعی با تأیید** (شرح دامنه → پاک‌سازی → گزارش صادقانه).

## وضعیت‌های سراسری
Loading (rThink/dots)، Empty (تاریخچهٔ خالی/درخواست خالی)، Error (errbar + E24 + toast نرخ‌محدود)، Success (toast + پیام ✓). بازیابی فلو پس از نوسازی: `S.wfs` + `E21.maybeResume`.
